# conways-game-of-life-but-arduino
conways game of life, but on an arduino and led matrices.
Another half life hackclub project. I was inspired by Conway's Game of Life by John Horton Conway. Its essentailly a zero-player game that plays itself based on the original orientation of all the pixels.
Right now I have a simple 8x8 pixel version of it, but I can easily scale that up once I get enough materials
I started with a prototype on python, which ive attached on this repo as the py file.
